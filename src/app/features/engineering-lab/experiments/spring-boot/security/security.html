ENGINEER

Inside the Implementation

Connect the behavior you just observed to the Spring Security components responsible for authentication and authorization.

SecurityFilterChain

Define Access Rules

.requestMatchers(
    "/api/lab/security/user"
)
.hasAnyRole("USER", "ADMIN")

.requestMatchers(
    "/api/lab/security/admin"
)
.hasRole("ADMIN")
PasswordEncoder

Verify Passwords Safely

@Bean

    return new BCryptPasswordEncoder();
}
