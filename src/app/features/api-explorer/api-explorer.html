API EXPLORER GUIDE

How to Use the API Explorer

Explore real Tech Journey data or experiment safely with temporary sandbox records.

MUSEUM API

The Museum API contains the real timeline data displayed throughout Tech Journey.

  • Use GET ALL EVENTS to view the complete timeline JSON.
  • Use GET BY ID to retrieve a specific timeline event.
  • Museum data is read-only.

CRUD SANDBOX

The sandbox lets you experiment with API operations without changing the real Tech Journey timeline.

  • POST — Create a new sandbox record.
  • GET — Retrieve one sandbox record by ID or view all sandbox records.
  • PUT — Update an existing sandbox record using its ID.
  • DELETE — Remove a sandbox record using its ID.

FINDING SANDBOX RECORDS

Select GET → ALL EVENTS to view the complete sandbox JSON collection and see the IDs of records currently available.

You can then enter one of those IDs when using GET, PUT, or DELETE.

VERIFY YOUR CHANGES

  • After POST, use GET by ID to retrieve the new record.
  • After PUT, use GET by ID to verify your changes.
  • After DELETE, use GET by ID and expect 404 Not Found, or use GET ALL EVENTS to confirm the record is gone.

REQUEST & RESPONSE

After sending a request, inspect the HTTP status, execution time, response size, response body, and request payload.

POST and PUT send JSON request payloads. GET and DELETE identify resources through the endpoint and do not send a request body.
